## 1. Prepare the file

1. Open **Admin panel**, then **Classes and Enrolments**, then **Import enrolments**.
2. Press **Download template**. Columns: `email, full_name, class, year_of_study, academic_year`. Required: `email` and `class`.
3. Put one row per student per class. Use the academic year (for example 2026/2027) when class names repeat across years.

## 2. Upload and preview

1. Choose the CSV file (or paste the CSV), and choose whether to **Create form classes that do not exist yet**.
2. Press **Preview import**. Nothing is saved yet. Fix any rows with errors, or use **Download error report**.
3. Press **Import rows** (or **Import only the valid rows**) and confirm.

New student accounts get credentials; download them once with **Download credentials CSV** and hand them over securely. A finished import can be undone with **Roll back import** from **Import history**.
