---
title: Add a teacher directly
audience: school_admins
order: 20
summary: Create a teacher account yourself and send them an invitation.
---

Use this when a teacher has not applied through the form.

1. Open **Admin panel**, then **Users and Permissions**, and press **Add user**.
2. Enter the full name and email, choose the role **Teacher** and your school, then press **Create user**.
3. The teacher gets an email with a link to set their password (valid for 72 hours). If the email could not be sent, a temporary password is shown once instead; give it to the teacher in person.
4. Open the new user and use **Assign subject** so they can create classes for their subjects.

If the invitation expires, open the user and press **Resend invite**.
