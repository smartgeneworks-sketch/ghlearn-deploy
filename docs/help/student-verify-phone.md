A verified phone number lets you sign in with your number instead of your email, and get a password-reset code by SMS.

## Steps

1. Sign in and open **Account** at the top of the page.
2. Under **Phone number**, enter your Ghana mobile number (for example 024 123 4567) and press **Verify**.
3. We send a 6-digit code by SMS. Enter it under **6-digit code**.
4. When it shows **Verified**, you are done.

## Good to know

- If you added a number when you signed up, it still needs this check once.
- Codes expire quickly. If yours does not arrive or has expired, wait a minute and ask for a new one.
- To stop using the number, press **Remove phone number**.
